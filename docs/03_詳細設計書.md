## 1. API詳細仕様

共通事項：
- Base URL: `http://localhost:8000`
- リクエスト／レスポンスはすべてJSON（`Content-Type: application/json`）
- バリデーションエラーは `400 Bad Request`、`{ "detail": "エラー内容" }` の形式で返却する
- 存在しないリソースへのアクセスは `404 Not Found`
- 一意制約違反（ニックネーム重複など）は `409 Conflict`

### A-01 ユーザー登録
`POST /api/users`

リクエスト
```json
{ "nickname": "たろう" }
```
- nickname: 文字列、1〜20文字、必須、一意

レスポンス（201 Created）
```json
{ "user_id": 1, "nickname": "たろう", "created_at": "2026-08-14T10:00:00" }
```

エラー
| ステータス | 条件 |
|---|---|
| 400 | nicknameが未入力、または21文字以上 |
| 409 | 既に同じnicknameが登録済み |

### A-02 ログイン
`POST /api/login`

リクエスト
```json
{ "nickname": "たろう" }
```

レスポンス（200 OK）
```json
{ "user_id": 1, "nickname": "たろう" }
```

エラー
| ステータス | 条件 |
|---|---|
| 400 | nicknameが未入力 |
| 404 | 該当ユーザーが存在しない（フロントエンドはこの場合A-01の登録に誘導する） |

### A-03 テトリミノ出現順序の取得
`GET /api/tetromino-sequence?bags=1`

- bags: 取得する「7種セット」の数（クエリパラメータ、省略時は1、最大5）
- 各セット内で7種類（I, O, T, S, Z, J, L）をランダムな順に1回ずつ含む（7-bagアルゴリズム）

レスポンス（200 OK）
```json
{ "sequence": ["T", "I", "L", "O", "S", "Z", "J"] }
```
※ `bags=2` の場合は要素数14（7種×2セット、セットごとに独立してシャッフル）

エラー
| ステータス | 条件 |
|---|---|
| 400 | bagsが1〜5の範囲外 |

### A-04 難易度設定の取得
`GET /api/difficulty-settings`

レスポンス（200 OK）
```json
[
  { "id": 1, "name": "easy",   "initial_fall_speed_ms": 1000, "score_multiplier": 1.0 },
  { "id": 2, "name": "normal", "initial_fall_speed_ms": 700,  "score_multiplier": 1.5 },
  { "id": 3, "name": "hard",   "initial_fall_speed_ms": 400,  "score_multiplier": 2.0 }
]
```

### A-05 スコア登録
`POST /api/scores`

リクエスト
```json
{
  "user_id": 1,
  "score": 4500,
  "level_reached": 5,
  "lines_cleared": 42,
  "difficulty": "normal"
}
```
- user_id: 整数、必須、存在するユーザーであること
- score, level_reached, lines_cleared: 0以上の整数、必須
- difficulty: "easy" / "normal" / "hard" のいずれか、必須

レスポンス（201 Created）
```json
{
  "score_id": 10,
  "user_id": 1,
  "nickname": "たろう",
  "score": 4500,
  "level_reached": 5,
  "lines_cleared": 42,
  "difficulty": "normal",
  "played_at": "2026-08-14T10:30:00"
}
```

エラー
| ステータス | 条件 |
|---|---|
| 400 | 必須項目の不足、difficultyが不正な値 |
| 404 | user_idに該当するユーザーが存在しない |

### A-06 ランキング取得
`GET /api/rankings?limit=10&difficulty=`

- limit: 取得件数（省略時10、最大100）
- difficulty: 絞り込み条件（省略可。省略時は全難易度から取得）

レスポンス（200 OK）
```json
[
  { "rank": 1, "nickname": "たろう", "score": 9800, "level_reached": 9, "difficulty": "hard", "played_at": "2026-08-14T09:00:00" },
  { "rank": 2, "nickname": "はなこ", "score": 8200, "level_reached": 7, "difficulty": "normal", "played_at": "2026-08-13T18:00:00" }
]
```
スコアの降順で並び替える。同点の場合はplayed_atが早い方を上位とする。

### A-07 プレイ履歴取得
`GET /api/users/{user_id}/history?limit=20`

レスポンス（200 OK）
```json
[
  { "score_id": 10, "score": 4500, "level_reached": 5, "lines_cleared": 42, "difficulty": "normal", "played_at": "2026-08-14T10:30:00" }
]
```
played_atの降順（新しい順）で返却する。

エラー
| ステータス | 条件 |
|---|---|
| 404 | user_idに該当するユーザーが存在しない |

## 2. データベース詳細設計

### 2.1 users テーブル

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | ユーザーID |
| nickname | VARCHAR(20) | UNIQUE, NOT NULL | ニックネーム |
| created_at | DATETIME | NOT NULL, DEFAULT 現在時刻 | 登録日時 |

### 2.2 scores テーブル

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | スコアID |
| user_id | INTEGER | NOT NULL, FOREIGN KEY → users.id | プレイヤー |
| score | INTEGER | NOT NULL | 獲得スコア |
| level_reached | INTEGER | NOT NULL | 到達レベル |
| lines_cleared | INTEGER | NOT NULL | 消去した合計ライン数 |
| difficulty | VARCHAR(10) | NOT NULL | 難易度（easy/normal/hard） |
| played_at | DATETIME | NOT NULL, DEFAULT 現在時刻 | プレイ日時 |

### 2.3 difficulty_settings テーブル

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | 難易度ID |
| name | VARCHAR(10) | UNIQUE, NOT NULL | 難易度名（easy/normal/hard） |
| initial_fall_speed_ms | INTEGER | NOT NULL | 初期落下速度（ミリ秒／1マス） |
| score_multiplier | FLOAT | NOT NULL | 得点倍率 |

### 2.4 初期データ（difficulty_settings）

| name | initial_fall_speed_ms | score_multiplier |
|---|---|---|
| easy | 1000 | 1.0 |
| normal | 700 | 1.5 |
| hard | 400 | 2.0 |

初期データはアプリケーション起動時、またはセットアップスクリプトで投入しておく（研修開始前に準備）。

## 4. テトリミノ回転仕様

初学者向けの研修であることを踏まえ、本システムでは**壁蹴り（ウォールキック）を行わない簡易回転方式**を基本仕様とする。SRS（Super Rotation System）準拠の壁蹴り対応は発展課題（任意）とする。

- 各テトリミノは4x4のグリッド上で、回転状態0/R/2/L の4パターンの座標をあらかじめ定義したテーブルとして持つ
- 回転操作時、回転後の座標に他のブロックまたは盤面外との衝突がある場合は回転をキャンセルする（回転前の状態を維持する）
- 各ミノの形状定義（回転状態ごとの座標配列）は、フロントエンド詳細実装時に一般的なテトリミノ定義（4x4グリッド表現）を使用する

## 5. 得点計算仕様

### 5.1 基本得点（1回のライン消去あたり）

| 同時消去ライン数 | 基本得点 |
|---|---|
| 1ライン | 100 |
| 2ライン | 300 |
| 3ライン | 500 |
| 4ライン（テトリス） | 800 |

### 5.2 最終加算得点の計算式

```
加算得点 = 基本得点 × レベル係数 × 難易度倍率(score_multiplier)
レベル係数 = 1 + (現在レベル - 1) × 0.1
```

難易度倍率はA-04で取得した`difficulty_settings.score_multiplier`を使用する。

### 5.3 レベルアップ条件

- 消去ライン数の累計が10の倍数に達するごとにレベルが1上がる（レベル1スタート）
- レベルアップ時の落下速度（ミリ秒／1マス）は以下の式で算出する

```
落下速度(ms) = max(初期落下速度(initial_fall_speed_ms) − (現在レベル − 1) × 50, 100)
```

（下限は100ms。それ以上は速くならない）

## 6. エラーハンドリング方針（共通）

| ステータス | 用途 |
|---|---|
| 400 Bad Request | 入力値の形式・範囲が不正な場合 |
| 404 Not Found | 指定したリソース（ユーザー等）が存在しない場合 |
| 409 Conflict | ニックネームの重複など、一意制約違反の場合 |
| 500 Internal Server Error | 想定外のサーバーエラー |

フロントエンドは、通信エラー・上記エラーレスポンスを受け取った場合、画面上にエラーメッセージを表示し、処理を継続不能な状態にしない（アプリを固まらせない）よう実装する。
